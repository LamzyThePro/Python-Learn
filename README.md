# Python Learn

A beginner-friendly Python fundamentals practice program. It uses a command-line menu to demonstrate core Python concepts through small, runnable examples.

## Topics Covered

- Variables and basic data types
- Printing and formatted strings
- String indexing, slicing, and methods
- Numbers and arithmetic operators
- User input and type conversion
- Conditional statements and logical operators
- `for` loops, `while` loops, nested loops, and `break`
- Functions, parameters, arguments, and return values
- Keyword arguments and default arguments
- Variable-length arguments with `*args`
- Basic geometry and physics calculations

## Running the Program

Make sure Python 3 is installed, then run:

```bash
python "Python Learn.py"
```

Choose a topic from the menu, or choose `Run all` to view the examples together. The program also includes standalone practice exercises after the menu examples.

## Project Structure

- `Python Learn.py` - Python fundamentals examples and the interactive menu
- `README.md` - Project overview and usage instructions

This project is intended for learning and experimentation. Read the examples, change the values, and run the program again to see how the output changes.
